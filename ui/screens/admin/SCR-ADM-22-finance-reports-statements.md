# SCR-ADM-22 — Finance: reports & statements

**Route:** `admin.<domain>/finance/reports?report=&from=&to=&granularity=&currency=` and `/finance/statements?partner=&from=&to=` · **Render:** Client · **App:** Admin

## Purpose
Answer the founders' recurring questions with fixed reports (D-513): revenue by product, by partner, by period, tax collected, refunds, outstanding payouts, profit by product (revenue − expenses, D-514). Produce partner statements as PDF and CSV for any period. All figures derive from the ledger (INR reporting currency with native amounts available, D-515).

## User/role
Super Admin; Admin (`finance.reports.read` scoped; statements own only).

## Entry points
Sidebar "Finance › Reports" / "Statements", partner cards "Statement", dashboard revenue widgets "Open report".

## Layout
- **Reports (desktop):** h1 "Reports".
- Left rail (220 px) listing the seven reports; right: report header (title, description), controls: date range with presets (This month, Last month, This FY, Last FY, Custom), Granularity (`Select` day/month/FY for by-period), Currency (INR / Native), Product / Partner filters where relevant, "Export CSV", "Print".
- Body: summary tiles (e.g. Gross, Net, Tax, Refunds), chart (Recharts: bar/line appropriate to report; stacked by product/partner), and a `DataTable` with totals row; rows drill down (product → allocations; partner → ledger lines; period → orders).
- Profit by product shows revenue, expenses, profit, margin %.
- The Refunds report also lists **overpayments** (customer credits: order, payment, `customer_credit_minor`, whether refunded or applied) from the `customer_credits` view (docs/05 §7, MASTER_SPEC §7 "Overpayment"); docs/06 API-FIN-09 must expose it (e.g. report key `customer_credits`).
- **Statements (desktop):** h1 "Partner statements".
- Form: Partner* (`Combobox`; Admin-role fixed to self), Period* (presets + custom), Format (PDF / CSV), "Include payouts" and "Include expense shares" switches, "Generate".
- Preview pane renders the statement structure (opening balance, allocations by order, refunds, expense shares, payouts, closing balance) before download.
- History table of generated statements (partner, period, format, generated by/at, download link valid 5 min → regenerate).
- **Phone / tablet (< lg):** not a supported layout — the admin app is designed for ≥ 1024 px (MASTER_SPEC §7 "Admin minimum width"). Below `lg` this screen renders the read-only "Open on a laptop" notice (docs/07 §3.4): page title, a one-line summary where cheap, links to Approvals and Notifications; no forms, tables or actions.

## Components
- shadcn/ui: `Tabs`/rail, `Select`, `DatePicker`, `Combobox`, `Switch`, `Button`, `Card`, `DataTable`, Recharts, `Skeleton`, `Alert`
- custom: `ReportHeader`, `StatTile`, `StatementPreview`.

## Content & copy notes
- Each report states its formula in a `Tooltip` (e.g. "Revenue by partner = Σ partner_allocation − Σ refund_partner_allocation").
- FX note: "INR equivalents use the rate stored on each entry at payment date." Statement footer: "Generated by CodeKraft admin on <date> · figures from immutable ledger".

## Interactions
- Report → `getReport` (API-FIN-09) with params; URL reflects state; CSV export client-side from rows (audited via `exportStatement`-style log).
- Statement → `exportStatement` (API-FIN-10) → signed URL; PDF via @react-pdf.
- Drill-down links to allocations/ledger with filters.

## States
- **Default:** Revenue by period, this FY, month granularity.
- **Loading:** tiles + chart skeleton.
- **Empty:** "No data for this period".
- **Error:** `Alert`; statement generation failure with retry.
- **Success:** download opens; toast "Statement ready".
- **Permission-denied:** Admin-role partner filter locked to self; revenue by partner shows own only.

## Responsive behaviour
- **< lg (phone, tablet):** read-only "Open on a laptop" notice (admin minimum width 1024 px, MASTER_SPEC §7; founder may override).
- **lg+:** lg+ rail + content; tv larger charts.

## Accessibility
- Charts with hidden data tables and summary sentences; totals row marked with `<tfoot>`; presets as buttons; print stylesheet.

## Motion
- Chart entry 400 ms. **Reduced motion:** static.

## Navigation
→ `/finance/allocations`, `/finance/ledger`, `/orders?from=&to=`, `/finance/partners`, `/finance/expenses`.

## Data dependencies
Tables: `T-ledger_entries`, `T-allocations`, `T-orders`, `T-order_items`, `T-payments` / `customer_credits` (view), `T-products`, `T-partners`, `T-payouts`, `T-expenses`, `T-refunds`, `T-fx_rates`, `T-media` (statement PDFs), `T-audit_logs`.
Queries/actions: `getReport` (API-FIN-09), `exportStatement` (API-FIN-10), `getPartnerBalances` (API-FIN-03).

## Requirement IDs
D-513, D-514, D-515, D-512, D-511, BR-17, D-1104, D-401.
