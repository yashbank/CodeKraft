System मेन्यू में Settings, Audit log और Admin users हैं।
1. थीम, मुद्रा, पेमेंट तरीके और साइट के बाकी विकल्पों के लिए Settings खोलें।
2. किसने क्या बदला यह देखने के लिए Audit log खोलें।
3. एडमिन और staff को बुलाने या संभालने के लिए Admin users खोलें।
Tip: ये स्क्रीन सिर्फ Super Admin के लिए हैं।
