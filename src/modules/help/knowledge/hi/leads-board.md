Leads उन्हीं लीड को Table या स्टेटस के कॉलम वाले Board के रूप में दिखाता है।
1. Leads खोलें। Table या Board स्विच से दृश्य बदलें।
2. Table में Unassigned pool, Overdue only, Priority और Source जैसे फ़िल्टर लगाएं। कॉलम में Name, Source, Status, Priority, Assigned और Next follow-up होते हैं।
3. पंक्ति के मेन्यू में Open, Assign to me, Set follow-up, Change status या Mark lost मिलता है।
4. New lead से हाथ से लीड जोड़ें (source Manual)।
Tip: Overdue only वही लीड दिखाता है जो Dashboard के Overdue follow-ups कार्ड में आती हैं।
