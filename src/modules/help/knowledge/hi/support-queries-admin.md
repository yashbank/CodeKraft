1. Queries खोलें। Query list से थ्रेड चुनें।
2. Pool से थ्रेड लेने के लिए Unassigned (claim) चुनें।
3. Reply में लिखें और Send दबाएं।
4. More thread actions से Create lead, View customer या Propose refund करें (जब थ्रेड Refund request हो)।
5. ग्राहक का काम हो जाए तो उसे Resolved या Closed करें।
फोन या ईमेल की बात दर्ज करने के लिए Log a query दबाकर ग्राहक खोजें। ग्राहक के जवाब का इंतज़ार करते थ्रेड पर Waiting दिखता है।
