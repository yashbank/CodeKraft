1. Leads खोलें। नई लीड के लिए Unassigned pool फ़िल्टर लगाएं।
2. पंक्ति के actions में Assign to me से लीड अपने नाम करें।
3. Set priority चुनकर Normal या High रखें।
4. Set follow-up चुनकर तारीख डालें। Overdue only छूटे फॉलो-अप दिखाता है।
5. लीड खोलकर Add note करें, Chat transcript या Original message देखें।
6. Change status, Send custom quote या Create project order से आगे बढ़ाएं।
7. डील न बने तो Mark lost चुनकर कारण लिखें।
खुद लीड जोड़ने के लिए New lead दबाएं (source Manual रहता है)।
