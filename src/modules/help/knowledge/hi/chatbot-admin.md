1. Chatbot खोलें (Growth के नीचे)।
2. Usage में Daily chatbot messages, Estimated cost और Users at cap देखें।
3. Conversations खोलकर Chat transcript पढ़ें। आगे के लिए Open lead या Open escalated query दबाएं।
4. Prompts में System prompt बदलें, Version notes जोड़ें और नया Prompt version सेव करें।
5. भरोसा करने से पहले Try a message से बॉट टेस्ट करें।
Platform cap और Escalation rate बताते हैं कि बॉट सीमा छू रहा है या बहुत चैट इंसानों को भेज रहा है।
