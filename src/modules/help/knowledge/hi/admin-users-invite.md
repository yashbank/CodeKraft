Admin यूज़र केवल super admin संभाल सकता है।
1. Admin users खोलें (System के नीचे)।
2. Invite: Invite admin दबाएं, Email डालें, Role चुनें (Super Admin, Admin या Staff)। ज़रूरत हो तो Also a partner ऑन करें। इनवाइट Approvals में जाता है ("Invite approval requested")।
3. रोल बदलना: पंक्ति के actions में Change role चुनें, फिर New role रखें।
4. हटाना: Delete account… चुनकर पुष्टि करें।
रोल बदलने और हटाने के लिए भी मंज़ूरी चाहिए। आख़िरी super admin को डिलीट नहीं कर सकते।
