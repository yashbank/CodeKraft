आप तय कर सकते हैं कि Dashboard पर कौन से विजेट, किस क्रम में और किस अवधि के लिए दिखें।
1. Dashboard खोलें। Range सूची से Last 7 days, Last 30 days, Last 90 days या This FY चुनें।
2. Customise दबाकर विजेट लाइब्रेरी खोलें और विजेट चालू या बंद करें। आपको सिर्फ अपनी भूमिका के विजेट दिखते हैं।
3. Edit layout दबाकर कार्ड खींचें या move earlier और move later बटन इस्तेमाल करें। पूरा होने पर Done दबाएं।
4. कार्ड के refresh आइकन से सिर्फ वही कार्ड दोबारा लोड करें, या उसके मेन्यू से Remove करें।
5. Reset to default से मानक लेआउट वापस लाएं।
Tip: लेआउट आपके अपने अकाउंट के लिए सेव होता है।
