चेतावनी: यह डेटा हमेशा के लिए मिटाता है और वापस नहीं हो सकता।
1. Settings खोलें, फिर Danger zone।
2. Data to delete में मिटाने वाला डेटा चुनें। Preview row counts से Rows to delete देखें।
3. Download backup दबाएं। जब तक यह न करें, रिक्वेस्ट बटन बंद रहता है।
4. Request site reset दबाएं।
5. पुष्टि वाले डायलॉग में साइट का नाम ठीक वैसा ही टाइप करें ("Type ... to confirm" बॉक्स), फिर Confirm site reset request दबाएं।
अभी कुछ नहीं मिटता: दूसरे super admin को Approvals में मंज़ूर करना होगा। Super admin अकाउंट, settings, roles, legal पेज और audit log हमेशा बचे रहते हैं।
