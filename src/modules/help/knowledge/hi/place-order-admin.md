जब ग्राहक ऑफलाइन भुगतान करे या आप सीधे प्रोजेक्ट बेचें, तब यह तरीका इस्तेमाल करें।
1. Orders खोलें और New manual order पर क्लिक करें।
2. Product order (offline sale) या Project order (client invoice) चुनें।
3. Registered customer चुनें (email से खोजें) या Invite customer दबाएं।
4. हर ऑफरिंग के लिए Add line दबाएं। ज़रूरत हो तो Currency, Discount amount और Apply tax सेट करें।
5. चाहें तो Record payment now ऑन करके Method, Amount received, Reference और Paid on भरें।
6. Create order दबाएं, या भुगतान दर्ज हो तो Create & confirm।
Project order में Create & request split approval दिखता है और वह पहले Approvals में जाता है।
