यह केवल super admin बदल सकता है।
1. Settings खोलें और General / seller पर जाएं।
2. Site phase ढूंढें।
3. एक चुनें:
- Live: सामान्य पब्लिक साइट।
- Testing: Test site बैनर दिखता है, सर्च इंजन को इंडेक्स न करने को कहा जाता है और ग्राहकों को ईमेल नहीं जाते।
- Maintenance: विज़िटर को back soon पेज दिखता है; admin और पेमेंट चलते रहते हैं।
4. Save changes दबाएं।
प्रयोग के लिए Testing, डाउनटाइम के लिए Maintenance रखें, और लॉन्च से पहले Live पर लौटें।
