Revocation tasks विजेट खुले Revoke external delivery tasks दिखाता है: रिफंड या revoke के बाद जिन बाहरी अकाउंट को बंद करना है।
1. Dashboard खोलें और Revocation tasks कार्ड देखें।
2. हर पंक्ति में प्रोडक्ट का नाम और Disable the external account लिखा होता है।
3. पंक्ति या View all पर क्लिक करके Delivery tasks खोलें।
4. बाहर अकाउंट बंद करें, फिर टास्क पर Mark done दबाएं।
Tip: खाली कार्ड पर No revocation tasks लिखा होता है।
