1. Coupons खोलें (Catalog के नीचे)।
2. New coupon पर क्लिक करें।
3. Code लिखें और Type & value में Percentage या तय राशि चुनें।
4. Starts at और Ends at सेट करें।
5. वैकल्पिक सीमाएं: Max redemptions, Restrict to products, First purchase only।
6. ज़रूरत हो तो Internal note जोड़ें, फिर Save coupon दबाएं।
Copy code से कोड शेयर करें। ग्राहक चेकआउट पर Coupon (optional) में इसे डालता है। कहां इस्तेमाल हुआ, यह View orders में दिखता है।
