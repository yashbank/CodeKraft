1. Products खोलें और प्रोडक्ट पर क्लिक करें।
2. Media टैब पर जाएं।
3. Choose file दबाएं। इमेज, MP4/WebM/MOV वीडियो और PDF चलते हैं।
4. एक्सेसिबिलिटी के लिए Alt text (optional) लिखें।
5. Upload & attach दबाएं। Media attached संदेश दिखेगा।
6. किसी इमेज को थंबनेल बनाने के लिए Use cover image दबाएं।
Cover image प्रोडक्ट कार्ड पर दिखती है। गलत हो तो उसी टैब से हटाएं। रिलीज़ डाउनलोड Versions टैब में Upload release file से जाते हैं।
