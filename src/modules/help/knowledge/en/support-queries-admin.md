1. Open Queries. Pick a thread from the Query list.
2. Choose Unassigned (claim) to take a thread from the Pool.
3. Type in Reply and click Send.
4. Use More thread actions for Create lead, View customer or Propose refund (when the thread is a Refund request).
5. When the customer is done, mark it Resolved or Closed.
To start a thread for a phone call or email, click Log a query and search the customer. Threads waiting on the customer show Waiting.
