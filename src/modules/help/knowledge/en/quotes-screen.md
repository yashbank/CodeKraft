Custom quotes lists quotes with Title, Customer, Amount, Status, Expires, Sent on, Order and Pay link.
1. Open Quotes. Use Filter by status to narrow the list.
2. To make one, create it, pick a customer, add a Title, Description (what's included), Price (tax-exclusive), Tax % and Valid until.
3. Use the row menu to Open, Copy pay link or Cancel.
4. Use Email preview to see what the customer receives.
Tip: the customer pays through the pay link.
