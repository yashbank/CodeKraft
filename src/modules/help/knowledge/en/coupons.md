---
1. Open Coupons (under Catalog).
2. Click New coupon.
3. Enter the Code and choose Percentage or a fixed amount under Type & value.
4. Set Starts at and Ends at.
5. Optional limits: Max redemptions, Restrict to products, First purchase only.
6. Add an Internal note if needed, then click Save coupon.
Use Copy code to share it. Customers type it in Coupon (optional) at checkout. Open View orders to see where it was used.
