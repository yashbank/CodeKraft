Leads shows the same leads as a Table or as a Board of columns by status.
1. Open Leads. Use the Table or Board switch to change the view.
2. In the Table, use filters such as Unassigned pool, Overdue only, Priority and Source. Columns include Name, Source, Status, Priority, Assigned and Next follow-up.
3. Open the row menu for Open, Assign to me, Set follow-up, Change status or Mark lost.
4. Click New lead to add one by hand (source Manual).
Tip: Overdue only matches the Overdue follow-ups dashboard card.
