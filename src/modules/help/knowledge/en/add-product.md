1. Open Products and click New product.
2. On the Basics tab fill the details, then click Create product.
3. On Content add the Short description and Rich description.
4. On Offerings & prices click Add offering, set Base price and payment method, then Save offering.
5. Set up Delivery config and Ownership / split.
6. Check the Readiness checklist.
7. On Publish / schedule click Submit for approval and confirm the request.
Staff can edit drafts but cannot submit. Products go live only after approval.
