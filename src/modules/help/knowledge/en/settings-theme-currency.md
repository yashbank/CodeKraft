1. Open Settings (under System). Staff and admins can view; only a super admin can save changes.
2. Use the section list: General / seller, Currencies, Tax & GSTIN, Payment methods, Theme, AI, Email & notifications, Feature flags, Fulfilment guide and Danger zone.
3. Theme: pick Light editorial or Dark cinematic as the default theme.
4. Currencies: set the Base currency and Enabled display currencies. Use Refresh now for exchange rates.
5. Click Save changes. "Settings saved" confirms it.
