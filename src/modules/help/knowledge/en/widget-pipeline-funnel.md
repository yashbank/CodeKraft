The Pipeline funnel widget shows how many leads sit in each stage: New, Contacted, Qualified, Proposal, Won and Lost.
1. Open Dashboard and find Pipeline funnel.
2. Each bar is one stage; longer means more leads. It counts all leads, not only yours.
3. If it says No leads in the pipeline yet, there are no leads.
4. To work the leads, open Leads or Leads board.
Tip: Customise on the Dashboard adds or removes this card (Super Admin only).
